# Sales Performance Dashboard

An interactive sales analytics dashboard built using **MySQL**, **Power BI**, and **Tableau**, analyzing 9,694 transactional records from the Sample Superstore dataset (2014–2017).

## Overview

This project covers the full data analytics pipeline — from raw data cleaning and SQL-based analysis to interactive dashboard development — surfacing actionable business insights for sales performance across regions, categories, products, and customers.

## Tools & Technologies

- **MySQL Workbench** — Database design, data import, and SQL analysis
- **Power BI Desktop** — DAX measures, KPI cards, and interactive visuals
- **Tableau Desktop** — Interactive charts and published workbook
- **Microsoft Excel** — Data cleaning and CSV export
- **HTML / CSS / Chart.js** — Standalone interactive web dashboard

## Key Insights

- **West region** generated the highest revenue at $713K out of $2.27M total sales
- **Technology** was the most profitable category at $145K profit
- **Furniture** showed the lowest profit margin ($17K) despite high sales volume
- **Q4 sales peaks** observed consistently across all 4 years
- **Sean Miller** was the top customer contributing $25K in revenue
- **Canon imageCLASS 2200** was the highest selling product at $61K

## SQL Queries Covered

- Total sales and profit aggregation
- Regional sales breakdown
- Category-level profit analysis
- Monthly sales trend extraction
- Top 10 products by revenue
- Top 10 customers by revenue

## Dashboard Features

- 4 KPI cards — Total Sales, Total Profit, Profit Margin, Total Orders
- Interactive region and category filters
- Monthly sales trend line chart (2014–2017)
- Sales by region and profit by category bar charts
- Top 10 products and customers tables
- Live web version built with HTML and Chart.js
